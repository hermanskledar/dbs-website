# Die Blauwe Schuite

Website van herendispuut Die Blauwe Schuite, gelieerd aan T.S.C. St. Olof in Tilburg. Gebouwd met Astro en te publiceren op Cloudflare Workers.

```bash
npm install
npm run dev
```

De site draait daarna op `http://localhost:4321`.

`npm run build` maakt de productiebuild. `npm run check` bouwt, typecheckt en doet een droge Cloudflare-deploy.
