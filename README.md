# Skledar Natuursteen

Website van Skledar Natuursteen, steenhouwerij en showroom aan de Energieweg in Waalwijk. Gebouwd met Astro en te publiceren op Cloudflare Workers.

```bash
npm install
npm run dev
```

De site draait daarna op `http://localhost:4321`.

`npm run build` maakt de productiebuild.
